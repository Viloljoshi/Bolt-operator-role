# Bolt · Principal Program Manager (Builder-Operator) application

A tailored single-page site for the Principal Program Manager (Builder-Operator), Rides Central Operations role at Bolt, by Vilol Joshi.

It answers every "About you" requirement with evidence, maps each main responsibility to how I would actually work, and shows the AI systems I have personally built and shipped.

## Run locally

```bash
python3 -m http.server 8910
# open http://localhost:8910
```

## Deploy (GitHub Pages)

Settings, then Pages, then Source: `main` / root. The site is plain static HTML, CSS, and JS.

## Files

| File | Purpose |
|------|---------|
| `index.html` | The application page |
| `styles.css` | Theme (warm gradient with a Bolt-green accent) |
| `main.js` | Scroll reveals, counters, cursor blob, rotator |
